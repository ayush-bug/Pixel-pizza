A Simple and clean pizza ordering web app built with javascript,vite and firebase .

I have use neobrutalism ui to make it clean and attractive .

It also has admin-dashboard to manage all orders .

## Live Demo 

**[Visit Pixel Pizza](https://ayush-bug.github.io/Pixel-pizza/)**


## Features 

- Add items in your cart
- Increase quantity of the item
- overall price calculation
- order with one click
- admin dashboard
- edit status form the admin page
- view all data in admin page
- check all and today's orders
- completed and pending order status

## language used in the project 
- html
- css
- javascript
- vite
- firebase

## tool used in the project

svg icons were taken from bootstrap icons `https://icons.getbootstrap.com/`

some example images like pizza img , deliver boy img taken from internet , i forgot the source `google.com`

I have also used grid generator to generate grid but very less use and also it was confusing tho it is better to create your own `https://cssgridgenerator.io/`

## env changes requried after you clone 
 <pre>
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_firebase_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_firebase_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
VITE_FIREBASE_APP_ID=your_firebase_app_id
 </pre>

change this api keys to your own api you can get it from `firebase.com` 

For more info `https://firebase.google.com/docs/web/setup`
